# CheremoSphere Official Hero Asset Directory

This directory holds the official hero graphic for CheremoSphere.

## Instructions for Project Owner (Japhet Cheremo):
1. Place your official CheremoSphere hero image file here named `hero-official.png` (or `hero-official.jpg` / `hero-official.webp`).
2. The website and mobile hero components automatically check for and display `hero-official.png`.
3. If no official hero file is placed yet, the system gracefully falls back to the modern vector placeholder `hero-placeholder.svg`.
4. The system preserves the exact image without distortion or artificial replacements.
